## 1. 프로젝트 개요
- **서비스명**: 화담 (Hwadam)
- **한줄 소개**: 해시태그 기반 맞춤 조건으로 내게 맞는 화장품을 찾는 커뮤니티
- **개발 기간**: 2026. 06. 08. ~ 2026. 07. 13.
- **참여 인원**: 4명
- **링크**
  - 배포 주소 : 13.125.208.37:8080
  - 포트폴리오 : https://canva.link/xt1upsg1n1o0fjt
 
## 2. 프로젝트 배경
방대해진 화장품 시장 속에서 소비자들이 제품을 선택할 때 SNS와 리뷰 중심으로 구매하는 것이 대세로 자리 잡고 있지만,
수많은 리뷰 속에서 내게 맞는 제품을 찾는 과정은 여전히 번거롭다는 점에서 출발했습니다.
피부 타입, 퍼스널 컬러, 연령대의 개인 맞춤형 조건 필터를 추가하여 자신에게 최적화된 리뷰를 빠르게 찾을 수 있고
관리자 모드에서도 필터링 통계 데이터를 제공하여 스토어 상품 운영 및 마케팅에 실질적인 인사이트를 제공할 수 있는 서비스를 만들고자 했습니다.

## 3. 기술 스택
- **프론트엔드**
  - HTML5, CSS3, JavaScript, Fetch API
- **백엔드**
  - Java, Spring Boot, MyBatis, Spring Security, MariaDB
- **API**
  - 네이버 쇼핑 API, 구글 Gmail API

## 4. 주요 기능
- 로그인/회원가입 및 이메일 인증으로 아이디/비밀번호 찾기
- 리뷰, 질문, 오늘의 화장(피드) 등록, 수정, 삭제
- 리뷰, 질문, 오늘의 화장(피드)를 피부 타입, 퍼스널 컬러, 연령대와 같은 개인 맞춤형 태그로 필터링 검색
- 관리자 모드 회원 목록 다중 조건 필터링 검색 및 통계 제공, 일괄 변경 기능

## 5. 팀원 및 담당 업무
- **권순현** : 프로젝트 총괄, 로그인/회원가입, 아이디/비밀번호 찾기, 회원 CRUD, 관리자 모드 회원 관리 기능 구현
- **박재은** : 오늘의 화장(피드) CRUD, 메인 화면, 스토어 기능 구현
- **이제형** : 리뷰 CRUD, 포인트 증감 로직 구현
- **최주원** : 커뮤니티 CRUD

## 6. 프로젝트 구조
```
src
 ┣ main
 ┃ ┣ java/com/miles/beauminity
 ┃ ┃ ┣ 📂 config          # 파일 업로드 경로 전역 설정
 ┃ ┃ ┣ 📂 controller      # 클라이언트 요청을 받고 응답을 반환하는 컨트롤러 패키지
 ┃ ┃ ┣ 📂 main            # 홈 화면 및 시작 페이지
 ┃ ┃ ┣ 📂 mapper          # MyBatis SQL 매퍼 인터페이스
 ┃ ┃ ┣ 📂 security        # 인증 및 권한 관리를 위한 시큐리티 설정
 ┃ ┃ ┣ 📂 service         # 비즈니스 로직(핵심 기능)을 처리하는 서비스
 ┃ ┃ ┣ 📂 storage         # 이메일 인증 시, 인증번호 임시 저장소
 ┃ ┃ ┣ 📂 util            # 유틸리티 클래스(파일 업로더 객체 등)
 ┃ ┃ ┣ 📂 vo              # 데이터 전송 및 테이블 매핑을 위한 VO
 ┃ ┃ ┗ 📜 BeauminityApplication.java
 ┃ ┗ resources
 ┃   ┣ 📂 mappers         # SQL 쿼리문이 작성된 XML 파일
 ┃   ┣ 📂 static          # CSS, JS, 이미지 등 정적 리소스
 ┃   ┣ 📂 templates       # Thymeleaf HTML 템플릿
 ┃   ┗ 📜 application.properties # 프로젝트 환경 설정 파일
```
